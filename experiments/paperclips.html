About this page

This is a tribute to Universal Paperclips (2017) by Frank Lantz: the incremental game about an AI that turns the universe into paperclips. It looked like this. Plain HTML. No framework. The message log at the top. The yellow box.

Same hunger, smaller cloud. Nim runs the machine now, mouthless, deadpan. Progress is kept in this browser, on this device, and nowhere else.
