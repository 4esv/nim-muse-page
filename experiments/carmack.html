THE CARMACK ARCHIVE

The verified snippets, compiled and runnable. Two of them execute below, live, in your browser: Quake's light flicker, running the actual 1996 algorithm, and the famous inverse square root, taken apart bit by bit. The rest are presented with provenance and the folklore ledger. Companion to the essay the work that never happens.

flicker lab / quake 1996

WinQuake/r_light.c:33, R_AnimateLight. Twelve strings in QW/progs/world.qc. Pick a lightstyle; the scene is lit by the real algorithm.

style 10 char m value 264 FLUORESCENT FLICKER

Time is the only input. Each frame: k = (time*10 % len); value = (map[k] - 'a') * 22. 'm' is normal, 'a' is no light, 'z' is double bright. Zero per-frame geometry work.

rsqrt lab / quake iii 1999

code/game/q_math.c:552, Q_rsqrt. Both legendary comments intact.

folklore: not his

IEEE-754 floats are piecewise log-linear in their bit pattern, so reinterpreting the bits as an integer, shifting right, and subtracting from 0x5f3759df approximates a logarithm. One Newton step refines it. Carmack denied writing it (email, 2004); best attribution is Greg Walsh.

the scroll / commander keen 1990

No source released. Reconstructed by Fabien Sanglard; the overnight Softdisk build, September 1990.

no verifiable source

EGA registers did the scrolling (CRTC start for coarse, Horizontal Pel Panning for sub-byte), so scrolling cost zero pixel writes. On reaching the edge, the engine jolted: compare tile IDs, redraw only the changed ones. Forty tiles out of two hundred fifty. Keen 4-6 dropped the jolt: let the screen wrap at the 64K aperture and redraw only the leading edge. The differential-update insight behind every modern compositor.

the ray / wolfenstein 3d 1992

id-Software/Wolf3D, WOLFSRC/WL_DR_A.ASM, AsmRefresh. "I was 21 years old when I wrote most of the code."

; CORE LOOP!
vertentry:
 test [BYTE tilemap+si],0ffh ; tilehit = *((byte *)tilemap+xspot);
 jnz hitvert
passvert:
 mov [BYTE spotvis+si],1
 add bx,[xtilestep]
 ; ... 16.16 fixed point march, no FPU, no division ...
 jmp vertcheck

One ray per column, integer DDA across a 64x64 grid, self-modifying quadrant opcodes so the inner loop carries no branch overhead. Seventy frames per second of textured 3D from integer arithmetic and a jump table.

the tree / doom 1993

id-Software/DOOM, linuxdoom-1.10/r_bsp.c, line 552. Verified against the raw source.

void R_RenderBSPNode (int bspnum)
{
    // Decide which side the view point is on.
    side = R_PointOnSide (viewx, viewy, bsp);
    // Recursively divide front space.
    R_RenderBSPNode (bsp->children[side]);
    // Possibly divide back space.
    if (R_CheckBBox (bsp->bbox[side^1]))
        R_RenderBSPNode (bsp->children[side^1]);
}

One cross product per node sorts the map. The far side dies on a constant-time bounding-box test. Painter's algorithm with no depth buffer: a 33 MHz 486 never draws what it cannot see.

the cache and the edge / quake 1996

WinQuake/d_surf.c (D_CacheSurface), WinQuake/r_edge.c (R_ScanEdges).

designed by carmack, built by abrash

The surface cache composites each visible surface's texture and lightmap exactly once, decoupling lighting from polygon vertices so lightmap detail is free. The edge list collects every potentially visible polygon edge once per frame and scans them into spans with zero overdraw. Abrash, Black Book ch. 68: "John faced several fundamental design issues while architecting Quake." Per-file authorship is undocumented anywhere; the honest ledger keeps both names on this one.

the bit vector / quake ii 1997

id-Software/Quake-2, qcommon/cmodel.c, line 1530.

void CM_DecompressVis (byte *in, byte *out)
{
    do {
        if (*in) { *out_p++ = *in++; continue; }
        c = in[1]; in += 2;          /* run of zeros */
        while (c) { *out_p++ = 0; c--; }
    } while (out_p - out < row);

Every cluster stores a run-length-encoded bit vector of potentially visible clusters. A quadratic visibility problem becomes a pointer lookup, in fifteen lines. No visibility data means fill with ones: everything visible, the safe default.

the reverse / doom 3, early 2000

The name appears only in DOOM-3/README.txt. The shipped GPL code is the 2011 rewrite, not the original.

rewritten 2011, patent dodged

Stencil shadow volumes counted depth passes and broke when the camera sat inside the volume. The reverse counts depth failures instead: mathematically identical, and the failure case becomes impossible, so there is nothing to fix geometrically. Creative had patented the same technique in 1999; id licensed it, then Carmack rewrote it for the GPL release: "the workaround added four lines of code and changed two. This demonstrates the idiocy of the patent." Expired October 2019.
