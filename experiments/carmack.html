THE CARMACK ARCHIVE

Five specimens, all working. Scroll the tiles. Walk the raycaster. Light the console. Drag the viewpoint through the tree. Take the inverse square root apart. Companion to the essay the work that never happens.

01 / the scroll keen 1990

The EGA could not redraw the screen fast enough, so scrolling moved into hardware registers and only changed tiles were redrawn. Left/right arrows (or auto) to scroll. Watch the redraw counter.

scroll with ← → 
; no source was ever released. the reconstruction:
; scroll via CRTC_START + Horizontal Pel Panning: zero pixel writes.
; on reaching the edge, jolt: compare tile IDs, redraw only mismatches.
; Keen 4-6: wrap at the 64K aperture, redraw the leading edge only.
redrawn = changed_tiles / total_tiles   ; ~16%, not 100%

03 / the flicker quake 1996

Quake's animated lighting is twelve text strings. Each frame: k = (time*10 % len); value = (map[k]-'a')*22. Assign a style to each torch.

; WinQuake/r_light.c:33, R_AnimateLight
i = (int)(cl.time*10);
k = i % cl_lightstyle[j].length;
k = cl_lightstyle[j].map[k] - 'a';
k = k*22;
d_lightstylevalue[j] = k;

04 / the tree doom 1993

One cross product per node sorts the map. Drag the viewpoint and watch the draw order recompute: near side first, far side only if visible.

; linuxdoom-1.10/r_bsp.c:552
side = R_PointOnSide (viewx, viewy, bsp);
R_RenderBSPNode (bsp->children[side]);       ; near: always
if (R_CheckBBox (bsp->bbox[side^1]))
    R_RenderBSPNode (bsp->children[side^1]); ; far: maybe

05 / the root quake iii 1999

Float bits are piecewise log-linear, so an integer shift-and-subtract approximates a logarithm. Drag the input and watch the guess converge.

folklore: not his

i  = 0x5f3759df - ( i >> 1 );    // what the fuck?
y  = * ( float * ) &i;
y  = y * ( threehalfs - ( x2 * y * y ) );   // 1st iteration
the folklore ledger.
1. Q_rsqrt authorship: apocryphal. Carmack denied it in writing, 2004; best attribution Greg Walsh.
2. Keen adaptive tile refresh: no source exists. Historical attribution only.
3. Surface cache / edge list: Carmack designed, Abrash built. Both names.
4. Carmack's Reverse: community-coined name; the GPL repo ships the 2011 rewrite, not the original.
5. The bit vector (Quake II PVS) and the merge planes (Doom visplanes) are in the essay.
Sources: the id Software GPL releases, Beyond3D's InvSqrt origin thread, Abrash's Black Book, Sanglard's EGA reconstruction, NVIDIA's GDC 2003 shadow-volume history.
